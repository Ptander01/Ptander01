# Patrick Anderson

**Spatial data scientist — research, build, present.**

I scope problems, collect the data, design the analysis, interpret the result, and
build the thing that lets someone else see it. Eleven years of that: statewide
hydrology for a state natural-resources agency, healthcare access modelling for the
Department of Veterans Affairs under Public Trust clearance, and most recently
GIS and remote sensing for AI data-centre infrastructure at Meta.

The spatial reasoning is not really about geography. The clearest demonstration in
my portfolio is a 3D brain atlas built from my own MRI — same segmentation,
meshing and rendering problems as terrain, different substrate.

**Portfolio → [pta-portfolio.vercel.app](https://pta-portfolio.vercel.app)** — 48 pieces,
6 case studies, filterable by industry, technique and format.

## Selected work

| Project | What it is |
|---|---|
| **[Solar Siting Explorer](https://github.com/Ptander01/solar-siting-explorer)** | Draw a study area anywhere in the US and a real Python geoprocessing pipeline runs against it on demand — SRTM elevation, ESA WorldCover, HIFLD transmission, USGS PAD-US — scored 0–100 and rendered with MapLibre GL JS + deck.gl. |
| **[Data Pipeline & Consensus Model](https://github.com/Ptander01/Updated-Data-Pipeline-and-Analysis)** | The eight-stage Python/arcpy pipeline behind the data-centre work at Meta.
